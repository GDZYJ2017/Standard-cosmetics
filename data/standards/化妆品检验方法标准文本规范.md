# 化妆品检验方法标准文本规范

> **适用范围**：化妆品/牙膏中目标物检验方法标准文本的起草、审查与修订
> **技术类型**：液相色谱-质谱联用法（LC-MS/MS）、气相色谱-质谱联用法（GC-MS）
> **参照范本**：国家药监局2026年第1号公告附件2-6（共5份已发布检验方法）

---

## 一、整体结构

### 1.1 章节顺序（固定）

```
标题（中文 + 英文）

1 范围
2 方法提要
3 试剂和材料
4 仪器和设备
5 分析步骤
  5.1 标准系列溶液的制备
  5.2 基质标准溶液的制备（如需）
  5.3 样品处理
  5.4 参考色谱/质谱条件
  5.5 定性判定
  5.6 定量测定
6 计算
  6.1 计算
  6.2 回收率和精密度
7 图谱
附录A（资料性）标准品信息表
附录B（规范性）质谱监测离子对参数（≥10种目标物时独立）
附录C（资料性）补充信息（按需）
```

### 1.2 结构检查清单

| 检查项 | 要求 |
|--------|------|
| 章节编号连续 | 1→2→3→4→5→6→7，无跳号 |
| 5.x子节完整 | 至少包含5.1/5.3/5.4/5.5/5.6；5.2按需 |
| 6.x子节完整 | 6.1计算 + 6.2回收率和精密度 |
| 附录标注 | 每个附录必须标注"资料性"或"规范性" |
| 附录B判定 | 目标物≥10种时独立为附录B；<10种嵌入正文5.4.2 |
| 附录编号 | A→B→C，按出现顺序 |

## 二、各章节写作规范

### 2.1 标题

**格式**：
```
[产品]中[目标物]的检验方法

Determination of [Target] in [Product]
```

**示例**：
- 化妆品中6α-甲基氢化可的松等124种原料的检验方法 / Determination of 6α-Methyl hydrocortisone and Other 123 Kinds of Ingredients in Cosmetics
- 化妆品中二甘醇的检验方法 / Determination of Diethylene Glycol in Cosmetics

**检查要点**：
- [ ] 中文标题与英文标题对应
- [ ] 英文标题首字母大写（介词/连词除外）
- [ ] 多组分时用"等N种"表述，英文用"and Other (N-1) Kinds of"
- [ ] 产品名称统一："化妆品"或"牙膏"，不混用

---

### 2.2 第1章 范围

**结构（三要素，按顺序）**：

**要素1 — 方法规定**：
> 本方法规定了[方法名称]测定化妆品中[目标物]的含量。
> 或（含筛查时）：
> 本方法规定了[方法名称]，包括定性筛查方法与定量测定方法。

**要素2 — 适用基质**：
> 本方法适用于[基质列表]化妆品中[目标物]的定性筛查与定量测定。

**要素3 — 目标物及参数指引**：
- 统一表述为：本方法所包含的[目标物]的中文名称、英文名称、CAS号等信息详见附录A。
- 附录A（标准品信息表）应始终设置，作为目标物详细信息的汇总。
- 质谱监测离子对参数的放置：目标物≥10种时，独立为规范性附录B；目标物<10种时，嵌入正文5.4.2节。

**基质分类标准用语**（按固定顺序）：
- 液体水基类、膏霜乳类、凝胶类、液体油基类、粉剂类、蜡基类

**检查要点**：
- [ ] 三要素齐全，顺序正确
- [ ] 基质分类用词与5.3样品处理中的分类一致
- [ ] 目标物统一引至附录A，不在范围中直接列出
- [ ] "含量"vs"定性筛查与定量测定"——根据方法实际能力选择，不得虚标

---

### 2.3 第2章 方法提要

**结构（两段）**：

**第一段 — 原理描述**：
> 本方法以[提取溶剂]为溶剂提取样品中[目标物]，经[分离仪器]分离，[检测器]检测，采用[定性方式]定性，[定量方式]定量，以[定量方法]计算含量。

**定性方式标准用语**：
- 保留时间和特征离子对的相对丰度比（LC-MS/GC-MS）
- 保留时间和特征离子的相对丰度比（GC-MS单四极杆）

**定量方式标准用语**：
- 定量离子对峰面积定量（三重四极杆）
- 定量离子同位素内标法定量（含内标时）
- 峰面积定量（无内标时）

**第二段 — 检出限与定量下限**：
> 本方法[目标物]的检出限均为[X] ng，定量下限均为[X] ng。取样量为[X] g[，定容体积为[X] mL]时，检出浓度均为[X] μg/g（或mg/kg），最低定量浓度均为[X] μg/g（或mg/kg）。

**检查要点**：
- [ ] 原理描述包含完整链条：提取→分离→检测→定性→定量→计算
- [ ] 检出限/定量下限标注单位（ng为绝对量，μg/g或mg/kg为浓度）
- [ ] 必须注明取样量条件（检出浓度和最低定量浓度依赖取样量）
- [ ] 多组分时检出限/定量下限用"均为"（统一值）或分列（不同值）
- [ ] 单位统一：同一方法中不混用μg/g和mg/kg（1 mg/kg = 1 μg/g）

---

### 2.4 第3章 试剂和材料

**结构**：

**总则句（必须）**：
> 除另有规定外，本方法所用试剂均为分析纯或以上规格，水为GB/T 6682规定的一级水。

**编号列表（3.1起，按以下顺序）**：

| 顺序 | 内容 | 编号 |
|------|------|------|
| 1 | 标准品 | 3.1 |
| 2 | 提取溶剂（色谱纯） | 3.2, 3.3... |
| 3 | 其他试剂 | 按使用顺序 |
| 4 | 自配溶液/缓冲液 | 按使用顺序 |
| 5 | 单标标准储备溶液 | 靠后 |
| 6 | 混合标准储备溶液 | 最后 |
| 7 | 耗材（滤膜等） | 最后 |

**标准品写法**：
- 多组分：标准品：[目标物概述]的标准品信息详见附录A。
- 少组分：标准品：[具体名称]，纯度大于[X]%，信息详见附录A。

**溶液配制写法**：
> [溶液名称]：[操作描述]，配制成浓度为[X]的[溶液类型]，于[温度]保存，有效期[X]。

**注的用法**（仅在有特殊要求时使用）：
- 放在相关试剂条目之后
- 内容：稳定性要求、特殊储存条件、临用新制等
- 示例：注：[某物质]不稳定，储备溶液需避光-18℃保存。定量测定时，需临用新制。

**检查要点**：
- [ ] 总则句存在且正确
- [ ] 编号连续，无跳号
- [ ] 标准品信息引至附录A（多组分）或直接给出（少组分）
- [ ] 储备溶液注明浓度、溶剂、储存温度、有效期
- [ ] 自配溶液给出完整配制方法（试剂名称+用量+溶剂+定容体积）
- [ ] 纯度要求：色谱纯/分析纯需明确标注
- [ ] 注仅用于特殊说明，不滥用

---

### 2.5 第4章 仪器和设备

**结构**：

编号列表（4.1起），按以下顺序：

| 顺序 | 内容 | 示例 |
|------|------|------|
| 1 | 主机仪器（含检测器类型） | 4.1 高效液相色谱-三重四极杆质谱联用仪 |
| 2 | 辅助仪器 | 4.2 分析天平 4.3 超声波清洗仪 4.4 涡旋混合仪 4.5 离心机 |

**写法规范**：
- 主机仪器：名称 + 关键配置（电离源类型、检测器类型等）
- 分析天平：必须注明感量（如"感量0.0001 g和0.00001 g"）
- 离心机：注明转速（如"转速可达8000 r/min"）
- 其他辅助仪器：名称即可，不需参数

**检查要点**：
- [ ] 编号连续
- [ ] 主机仪器含关键配置信息
- [ ] 分析天平注明感量
- [ ] 不列出常规实验室通用设备（如容量瓶、移液枪等）

### 2.6 第5章 分析步骤

#### 5.1 标准系列溶液的制备

**内容**：描述从储备溶液逐级稀释得到标准系列的过程。

**写法**：
> 精密移取[储备溶液]（3.x）[体积]于[容量瓶]中，用[溶剂]（3.x）稀释并定容至刻度，配制成浓度为[浓度列表]的标准系列溶液。

**检查要点**：
- [ ] 引用试剂编号（如"3.7"）
- [ ] 给出完整的浓度系列（至少5个浓度点）
- [ ] 注明稀释溶剂

#### 5.2 基质标准溶液的制备（如需）

**使用场景**：需要补偿基质效应时。

**写法**：
> 称取空白基质样品[X] g，加入[标准溶液]（3.x）[体积]，按"5.3"项下方法处理，配制成浓度为[浓度列表]的基质标准系列溶液。

**检查要点**：
- [ ] 明确空白基质来源
- [ ] 引用5.3的样品处理方法
- [ ] 如不需要基质标准，此节可省略

#### 5.3 样品处理

**结构**：按基质分类，每类一个子节。

**分类标准**（按固定顺序）：
1. 膏霜乳液类
2. 液体水基类
3. 凝胶类
4. 液体油基类
5. 粉剂类
6. 蜡基类

**处理方法相同的基质可合并**，如"膏霜乳液类、液体水基类、凝胶类"。

**每类处理方法的写法要素**：
> 称取样品[X] g（精确至[X] g），置于[容器]中，加入[溶剂]（3.x）[体积]，[前处理操作]，[分离操作]，取[上清液/滤液]待测。

**常见前处理操作**：
- 超声提取：超声波清洗器超声[X] min
- 涡旋混合：涡旋混合仪混合[X] min
- 离心：离心机[X] r/min离心[X] min
- 过滤：经[X] μm微孔滤膜过滤
- 净化（如需）：加入[净化试剂]，[操作描述]

**检查要点**：
- [ ] 基质分类与第1章范围中的基质列表一致
- [ ] 每类处理方法包含：取样量→提取溶剂及体积→前处理→分离→待测
- [ ] 精确度要求与天平感量匹配（精确至0.0001 g需0.00001 g感量天平）
- [ ] 引用试剂编号
- [ ] 特殊基质（如蜡基）有额外处理步骤（如加热融化）

#### 5.4 参考色谱/质谱条件

**结构**：

**5.4.1 液相色谱/气相色谱条件**（表格形式）：

| 参数 | 条件 |
|------|------|
| 色谱柱 | [柱型号]（[规格]），或等效色谱柱 |
| 柱温 | [温度]℃ |
| 流动相 | [组成]及梯度条件 |
| 流速 | [X] mL/min |
| 进样量 | [X] μL |
| ... | ... |

**梯度洗脱程序**（如需）：另起表格。

**5.4.2 质谱条件**：

**目标物<10种**：直接嵌入正文，表格形式：

| 目标物 | 电离方式 | 母离子 | 定量离子对 | 定性离子对 | 碰撞能量/V |
|--------|----------|--------|------------|------------|------------|
| ... | [M+H]+ | m/z | m/z → m/z* | m/z → m/z | X |

**目标物≥10种**：此处仅概述，具体参数引至附录B：
> 各目标物的监测离子对及碰撞能量等参数详见附录B。

**检查要点**：
- [ ] 色谱条件含完整参数：色谱柱、柱温、流动相、流速、进样量
- [ ] 梯度洗脱程序以表格形式呈现
- [ ] 质谱条件含电离方式（ESI+/ESI-、EI等）
- [ ] 定量离子对标注*号
- [ ] 附录B判定正确（≥10种引至附录，<10种嵌入正文）

#### 5.5 定性判定

**内容**：规定定性判定的标准。

**标准写法**：
> 在相同试验条件下，样品中待测组分的保留时间与标准溶液中对应组分的保留时间一致（偏差不超过±X%），且样品中待测组分的定性离子对的相对丰度比与浓度相当的标准溶液相对丰度比的偏差不超过表X规定的范围，可判定样品中存在该目标物。

**相对离子丰度比允许偏差表**（必须包含）：

| 相对离子丰度（K） | K>50% | 50%≥K>20% | 20%≥K>10% | K≤10% |
|-------------------|-------|------------|------------|-------|
| 允许的最大偏差 | ±20% | ±25% | ±30% | ±50% |

**检查要点**：
- [ ] 保留时间偏差有量化标准
- [ ] 相对离子丰度比偏差表完整（4个区间）
- [ ] 偏差数值与范本一致（±20%/±25%/±30%/±50%）

#### 5.6 定量测定

**内容**：描述定量测定的操作流程。

**标准写法**：
> 取标准系列溶液（5.1）[和基质标准系列溶液（5.2）]分别进样，记录色谱图，以标准系列溶液浓度为横坐标，[定量离子对]峰面积为纵坐标，绘制标准曲线。
>
> 取样品待测溶液进样，记录色谱图，测得峰面积，根据标准曲线得到样品待测溶液中[目标物]的浓度。

**检查要点**：
- [ ] 引用5.1（和5.2）
- [ ] 标准曲线描述完整（横纵坐标）
- [ ] 超出线性范围时的处理方式（稀释后重测）

### 2.7 第6章 计算

#### 6.1 计算

**结构**：公式 + 符号说明 + 结果表述 + 精密度要求

**公式写法**：
> 按式（1）计算样品中[目标物]的含量：
>
> ω = (ρ₁ - ρ₀) × V × D × 1000 / (m × 1000 × 1000)

**符号说明格式**（每个符号一行）：
> 式中：ω —— 样品中待测元素/组分的含量，mg/kg（或μg/g）；
> ρ₁ —— 测试溶液中待测组分的质量浓度，μg/mL（或μg/L）；
> ρ₀ —— 空白溶液中待测组分的质量浓度，μg/mL（或μg/L）；
> V —— 样品消化液定容体积，mL；
> D —— 试样稀释倍数；
> m —— 样品取样量，g。

**结果表述**：
> 以重复性条件下获得的两次独立测定结果的算术平均值表示，结果保留[X]位有效数字（或精确到小数点后X位）。

**精密度要求**：
> 在重复性条件下获得的两次独立测定结果的绝对差值不得超过算术平均值的[X]%。

**精密度分档写法**（含量范围不同时）：
> 样品中待测组分含量大于[X] mg/kg时，绝对差值不得超过算术平均值的10%；小于或等于[X] mg/kg且大于[X] mg/kg时，不得超过15%；小于或等于[X] mg/kg时，不得超过20%。

**检查要点**：
- [ ] 公式完整，变量定义清晰
- [ ] 符号说明每个符号一行，含名称和单位
- [ ] 单位体系一致（公式两侧单位平衡）
- [ ] 结果保留位数有明确规定
- [ ] 精密度要求有量化标准（百分比）
- [ ] 含内标时公式中包含内标校正项

#### 6.2 回收率和精密度

**标准写法**：
> 多家实验室验证的回收率为[X]%～[X]%，相对标准偏差小于[X]%（n=6）。

**检查要点**：
- [ ] 回收率范围合理（通常80%～120%）
- [ ] RSD有明确上限
- [ ] 标注验证实验室数量（"多家"或具体数量）
- [ ] 标注重复次数（n=6）

### 2.8 第7章 图谱

**内容**：标准溶液的色谱图。

**要求**：
- 每种目标物至少一张标准品色谱图（多组分可合并为一张总图）
- 标注：图号 + 图题
- 图题格式：图X [标准溶液类型]色谱图
- 图注：标注各峰对应的物质名称和保留时间

**示例**：
> 图1 混合标准溶液的多反应监测（MRM）色谱图
> 1：[物质A]（X.XXX min）；2：[物质B]（X.XXX min）；...

**检查要点**：
- [ ] 图号连续
- [ ] 图题含检测模式（MRM/SIM等）
- [ ] 各峰标注物质名称和保留时间
- [ ] 峰形正常，分离度满足要求

### 2.9 附录A（资料性）标准品信息表

**标注**：
> 附录A
> （资料性附录）
> [目标物]标准品信息表

**表格列**（按以下顺序）：

| 列 | 内容 | 是否必须 |
|----|------|----------|
| 序号 | 1, 2, 3... | 必须 |
| 中文名称 | 目标物中文名 | 必须 |
| 英文名称 | 目标物英文名 | 必须 |
| CAS号 | CAS Registry Number | 必须 |
| 分子式 | Molecular Formula | 必须 |
| 相对分子质量 | Molecular Weight | 必须 |
| 纯度 | ≥XX% | 推荐 |

**注的用法**（如需）：
- 放在表格之后
- 示例：注：括号内为目标成分分子量；实际标准品可能以盐类、水合物等形式提供，需根据实际标准品信息（纯度、分子量）折算至目标成分含量。

**检查要点**：
- [ ] 标注"资料性附录"
- [ ] 表格列完整（至少序号/中文名/英文名/CAS/分子式/分子量）
- [ ] 序号与正文/附录B中的序号一一对应
- [ ] CAS号格式正确（含连字符）
- [ ] 盐类标准品注明目标成分折算方式（如有）

### 2.10 附录B（规范性）质谱监测离子对参数

**适用条件**：目标物≥10种时独立为附录B；<10种嵌入正文5.4.2。

**标注**：
> 附录B
> （规范性附录）
> [目标物]质谱监测离子对参数

**表格列**：

| 列 | 内容 | 是否必须 |
|----|------|----------|
| 序号 | 与附录A对应 | 必须 |
| 中文名称 | 目标物中文名 | 必须 |
| 电离方式 | [M+H]+ / [M-H]- / EI | 必须 |
| 母离子 | m/z | 必须 |
| 定量离子对 | 子离子 m/z（标注*） | 必须 |
| 定性离子对 | 子离子 m/z | 必须 |
| 碰撞能量 | V | 必须 |

**检查要点**：
- [ ] 标注"规范性附录"
- [ ] 序号与附录A一一对应
- [ ] 定量离子对标注*号
- [ ] 碰撞能量有具体数值

## 三、通用要素规范

### 3.1 表格格式

- 表号连续：表1、表2...（附录中为表A.1、表B.1...）
- 表题在表格上方
- 表格列对齐，数值列右对齐
- 表注在表格下方（如有）
- 空白单元格用"—"填充

### 3.2 公式格式

- 公式居中，编号右对齐：式（1）、式（2）...
- 符号说明在公式下方，"式中："起头
- 每个符号一行：符号 —— 含义，单位；
- 单位用国际单位制（μg/mL、mg/kg、ng等）

### 3.3 "注"的用法

- 用于补充说明、特殊要求、注意事项
- 放在相关段落或条目之后
- 不替代正文内容
- 不在"注"中引入新的技术要求
- 多个注时编号：注1：... 注2：...

### 3.4 数值与单位规范

| 规则 | 正确 | 错误 |
|------|------|------|
| 数值范围用波浪号 | 0.1~0.5 mL | 0.1-0.5 mL |
| 单位与数值间空格 | 10 mg | 10mg |
| 精度匹配 | 0.00001 g（感量） | 0.0001 g（称至0.00001 g） |
| 浓度单位统一 | μg/mL 或 μg/g | 混用ppm |
| 温度范围 | 15℃~25℃ | 15-25℃ |
| 百分比范围 | 85%~115% | 85-115% |

### 3.5 交叉引用规范

- 引用章节：用阿拉伯数字编号（如"按5.3项下方法"）
- 引用试剂：用3.x编号（如"甲醇（3.1）"）
- 引用附录：用附录字母+编号（如"详见附录A"）
- 引用表格：用表号（如"见表1"）
- 引用公式：用式号（如"按式（1）计算"）

### 3.6 语言风格

- 使用第三人称客观表述，不用"我们""本文"
- 技术描述准确、简洁，不含主观评价
- 禁止使用"大概""左右""差不多"等模糊表述
- 条件句用"若...则..."或"如...应..."
- 强制性要求用"应"，推荐性用"宜"
