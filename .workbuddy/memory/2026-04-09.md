## 2026-04-09: Claw 规范原文全文审查功能升级

### 核心改进
用户指出 Claw 审查结果与同一人用 chatbot + 规范 md 直接生成的 docx 审查报告差距很大，根本原因是：AI 没有拿到完整的规范原文，只收到规则引擎的碎片化问题列表。

**改造方案**：
1. 规范文档复制到 data/standards/化妆品检验方法标准文本规范.md
2. config.py 新增 SPEC_INSPECTION_METHOD 常量
3. i_service.py 新增 SPEC_INSPECTION_COMPARE_PROMPT（全文规范对照审查 Prompt，输出四分类JSON：结构/内容规范性/一致性/格式规范）
4. i_service.py 新增 specification_review() 方法，AI 同时收到完整规范原文 + 完整初稿全文
5. 
eview_service.py 检验方法审查流程改造：规则检查 → 术语检查 → **AI规范原文全文审查**（核心） → 共识审查（仅多参考时）

### 新审查流程（检验方法文档）
- 15%: 规则引擎（InspectionMethodChecker，14维度）
- 40%: 术语检查（TerminologyChecker）
- 60-90%: AI规范原文全文审查（**新增，specification_review**）
- 92-100%（仅多参考时）: 共识感知审查（compare_documents）

### 修改文件
- ackend/config.py: 新增 SPEC_INSPECTION_METHOD 路径
- ackend/services/ai_service.py: 新增 SPEC_INSPECTION_COMPARE_PROMPT + specification_review()
- ackend/services/review_service.py: 改造检验方法审查流程
