## 审查任务永远 pending 根本原因修复
- 问题：提交审查任务后，进度永远停在 pending/0%，功能完全不工作
- 根本原因：`asyncio.create_task()` 将已 commit/关闭的 FastAPI db session 传入后台任务，后台任务首次写数据库就崩溃，error 被 except 吞掉，status 无法更新为 running 或 failed
- 修复：
  1. 抽取独立函数 `_update_task_in_db()`，每次调用自己开新 session（`async for db in get_db()`）
  2. `_run_review_task` 签名去掉 `db_session` 参数，完全依赖独立 session
  3. 清理了 2 条历史卡死的 pending 任务
- 同期修复：async progress_callback 未 await 导致 AI 分析阶段进度卡死
- **YAML 语法错误（根本原因）**：`rules/gbt_1_1_2020.yaml` 第 83 行 check 字段值包含中文引号 `"规范性引用文件"`，整行用英文双引号包裹，导致 YAML 解析器把中文引号当普通字符处理，字符串提前关闭，引发 ParserError。修复：改用 YAML 单引号包裹该字符串
- 教训：配置文件中的中文引号必须用单引号包裹，外层也用单引号；或统一把含中文引号的字段放在 `data/` YAML 中避免解析歧义
- 术语检查器误报修复：`cosmetic_terms.yaml` 中 `二极管阵列检测器` 的别名 `二极管阵列` 是主术语子串，原先 `alias in full_text` 的简单字符串匹配会把"二极管阵列检测器"中的子串也识别为别名独立出现，导致误报"多种写法"。修复：在 `_check_builtin_terms_usage` 中先排除作为其他注册术语子串的 alias，再用 `(?<![\u4e00-\u9fff])` 中文 CJK 边界判断 alias 是否为独立词

## 术语检查"多种写法"误报修复（操作类术语）
- 问题：用户报告"过滤""定容"等操作类术语被误报"多种写法"，但实际文档中只是正确地描述了不同操作
- 根本原因：
  1. `cosmetic_terms.yaml` 中"过滤"的 aliases `["0.22μm滤膜过滤","微孔滤膜过滤","滤膜过滤"]` 把"具体操作名称"错误地当作"同义词"——"微孔滤膜过滤"是具体的过滤方法，不是"过滤"的同义词
  2. 同样的问题出现在"定容" aliases `["定容至","稀释至刻度"]`——"定容至"是"定容至刻度"的省略说法，不是独立的同义词
  3. 检查器正则 `(?<![\u4e00-\u9fff])alias(?![\\u4e00-\\u9fff])` 对"0.22 µm滤膜过滤"中的"滤膜过滤"会误匹配（µ 是非 CJK 字符，打断了中文边界）
  4. 检查器把所有 aliases 都当作"可互换同义词"处理，但操作类 aliases 描述的是"相关但不同的具体操作"
- 修复：
  1. `cosmetic_terms.yaml`："过滤" aliases 清空；"定容" aliases 清空
  2. `terminology_checker.py` 新增 `_OPERATION_CATEGORIES` 集合（分离操作、浓缩操作、净化操作、配制操作等），检查器遇到这些 category 的 term 时直接跳过"多种写法"检查
  3. 对仪器/试剂/耗材类术语的正则增加"单位后缀"判断：alias 后面紧跟 µm/mL/g 等单位时说明是某完整操作名称的子串，不算独立出现
- 教训：aliases 设计原则——只有真正的可互换同义词（如 HPLC=高效液相色谱仪，DAD=二极管阵列检测器）才能作为 aliases；操作类术语的 aliases 应描述完全相同的动作（如"涡旋"="涡旋混匀"），而不是"具体操作名"与"一般操作名"的关系

## AI 提示词修复：试剂名称和章节错位误报（19:49）
- 问题1：AI 把"初稿用甲酸、参考用甲醇"报为"严重错误"，但这是两种完全不同化学物质，方法改进完全合理
- 问题2：AI 把"初稿3.4节是试剂配制、参考3.4节是试剂规格"报为"根本性章节错位错误"，但两个独立文档章节结构不同是正常的
- 根本原因：`ai_service.py` 两个 Prompt（通用标准 + 检验方法）都没有告知 AI"差异 ≠ 错误"的原则，且没有说明章节编号只是匹配线索
- 修复（两个 Prompt 都已更新）：
  1. **通用标准 Prompt**：新增"章节编号仅作匹配线索，不代表对应证明；以初稿内容为准评估其自身质量"
  2. **检验方法 Prompt**：大幅扩充审查原则：
     - 章节编号仅作匹配线索，不代表对应证明
     - 内容主题不同 ≠ 章节错位（初稿3.4节内容与参考3.4节不同，完全正常，不报任何错误）
     - 以初稿内容为准，评估其自身质量，不因使用不同试剂/仪器/细节就判错误
     - 只有当差异导致检测灵敏度/准确度/精密度明显下降时才标记问题
     - 内容主题相差很大时直接跳过对比，不报告误导性错误
